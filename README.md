# Download mobyx

**[Download the latest version](https://github.com/arvan-workflow/mobyx-releases/releases/latest)**  ·  Windows 10 and 11, 64-bit

mobyx automates real Android phones and virtual Android devices from
your PC: workflows you build by connecting nodes, a device wall for
running many phones at once, isolated browser environments, and an
assistant that knows your setup.

## What each release contains

| File | What it is |
| --- | --- |
| `mobyx-setup.exe` | The installer. This is the file to download. |
| `mobyx-setup.exe.sha256` | Its checksum, so you can confirm the download is intact. |

To check a download, open PowerShell in your Downloads folder and run
`Get-FileHash mobyx-setup.exe -Algorithm SHA256`. The result should
match the text in the `.sha256` file.

## Updates

mobyx checks this page for new versions and installs them itself, so
you only need to download the installer once.

## About this repository

This repository holds published builds only. The application's source
code is kept in a separate, private repository. Release notes for each
version are on the release itself.
